Khái niệm:: 
NGO đầu tư sinh kế vô các cộng đồng nghèo khó:
• kẻ đc ng ko, quay ra ganh ghét nhau
• làm méo mó thị trường, cạnh tranh thiếu lành mạnh
• thấy bở đào mãi, xin đc lần rồi xin hoài, ko chịu đầu tư cố gắng
• thằng giàu thì đi xin, thằng nghèo thì vẫn hoàn nghèo
• chia rẽ phá nát cấu trúc cộng đồng tương trợ nhau
